# Практична робота №6. Конструктивна модель вартості COCOMO

Об'єкт оцінювання – власний вебзастосунок Visitera (28 548 рядків коду, виміряно в ПР2).

| Файл | Призначення |
|------|-------------|
| `cocomo_data.py` | Коефіцієнти моделей (таблиці 19–25 методички) і рейтинги параметрів Visitera з обґрунтуванням |
| `cocomo_models.py` | Базова і проміжна COCOMO, COCOMO II (Early Design, Post-Architecture), вплив SIZE, порівняння моделей при високій новизні |
| `tool_check.py` | Звірка з онлайн-калькулятором COCOMO II (softwarecost.org) і знімок його сторінки |
| `results/` | Підсумки, графіки, результати звірки |
| `ІП-33_Ломакін_ПР6.pdf` | Звіт |

## Запуск

Потрібні Python з matplotlib і результати ПР2; для `tool_check.py` – curl і Google Chrome.

```
python cocomo_models.py
python tool_check.py <каталог для збереженої сторінки калькулятора>
```
