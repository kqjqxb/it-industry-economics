# Практична робота №3. Аналіз функціональних точок

Об'єкт аналізу – власний вебзастосунок Visitera (той самий, що в ПР2).

| Файл | Призначення |
|------|-------------|
| `fpa_data.py` | Вихідні дані: логічні файли (ILF, EIF) з таблицями й полями, транзакції (EI, EO, EQ) з полями й FTR, оцінки 14 характеристик системи |
| `fpa.py` | Складність за матрицями, UFP, TDI, VAF, AFP, оцінка SLOC і економічних характеристик, графіки |
| `results/` | Перелік функцій зі складністю, підсумки, графіки |
| `ІП-33_Ломакін_ПР3.pdf` | Звіт |

## Запуск

Потрібні Python з matplotlib і результати ПР2 (`../pr2/results`).

```
python fpa.py
```
