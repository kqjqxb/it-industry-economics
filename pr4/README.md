# Практична робота №4. Додаткові види точок для оцінки розміру ПЗ

Об'єкт оцінювання – власний вебзастосунок Visitera (той самий, що в ПР2 і ПР3).

| Файл | Призначення |
|------|-------------|
| `points_data.py` | Вихідні дані: алгоритми, екрани, звіти, компоненти 3GL, актори, варіанти використання, технічні фактори і фактори середовища |
| `points.py` | Feature points, Object points, Use-case points (методи 1 і 2), порівняння трудомісткості й вартості, діаграми |
| `results/` | Підсумки розрахунків, діаграми варіантів використання і діяльності, графік порівняння |
| `ІП-33_Ломакін_ПР4.pdf` | Звіт |

## Запуск

Потрібні Python з matplotlib, Graphviz (`dot`) і результати ПР2 та ПР3.

```
python points.py
```
