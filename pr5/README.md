# Практична робота №5. Оцінювання вартості ПЗ за методом аналогії

База – 21 відкритий проєкт GitHub (онлайн-запис, бронювання, планування), «новий» проєкт – OpenSalon.

| Файл | Призначення |
|------|-------------|
| `projects.py` | Проєкти бази з адресами репозиторіїв, вибір «нового» проєкту |
| `collect.py` | Клонування репозиторіїв, атрибути з історії git, розмір (cloc), мова, зусилля (розробнико-місяці) |
| `analogy.py` | Нормування, евклідова й манхеттенська відстані, калібрування «залиш одного», три аналоги, оцінка зусиль і вартості |
| `results/database.csv`, `results/database.xlsx` | Database проєктів з відстанями (аналоги виділено кольором) |
| `results/` | Сирі дані, підсумки, графік відстаней |
| `ІП-33_Ломакін_ПР5.pdf` | Звіт |

## Запуск

Потрібні git, cloc, Python з matplotlib і openpyxl.

```
python collect.py <каталог для клонів>
python analogy.py
```
