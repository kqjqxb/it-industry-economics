# Практична робота №7. Оцінка розміру (економічних показників) в Agile методах (Scrum)

Product Backlog подальшої розробки Visitera, оцінений методом Bucket System.

| Файл | Призначення |
|------|-------------|
| `backlog.py` | Епіки, еталонні історії, Product Backlog з оцінками в story points і поясненнями, параметри команди |
| `scrum.py` | Швидкість, кількість спринтів, вартість SP і беклогу, план релізів, графіки |
| `results/` | Підсумки, `product_backlog.csv`, графіки епіків і burndown |
| `ІП-33_Ломакін_ПР7.pdf` | Звіт |

## Запуск

Потрібні Python з matplotlib і результати ПР2.

```
python scrum.py
```
